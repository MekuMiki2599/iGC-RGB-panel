# iGCRGB v2.0.0

> 七彩虹 iGame 主板灯光的独立控制面板 —— 不启动 iGame Center，也能应用你的 ARGB 灯光预设。

🤖 **本项目完全由 DeepSeek AI 开发**（代码、界面、脚本、文档），人类仅负责需求、实机测试与发布。

## 📦 下载与安装

1. 下载 `iGCRGB_v2.0.0_win-x64.zip` 并解压；
2. 双击 **`setup-vendor.bat`**，按提示选择本机 **iGC.Lite 安装目录**，脚本会自动复制运行所需的 7 个厂商 DLL；
3. 双击 `iGCRGB.exe` 启动。

> ⚠️ 由于版权原因，发布包**不包含**七彩虹的闭源灯光组件（`iGameAPI.Contracts.dll`、`iGameAPI\*.dll`）。
> 这些组件需要从你自己电脑上已安装的 iGC.Lite 中复制；没安装 iGC 的话请先从七彩虹官网安装 iGame Center。
> 也可以按压缩包内的 `组件说明.txt` 手动复制。

## ✨ 亮点

- 🎛 18 种灯效完整移植：关灯 / 常亮 / 呼吸 / 色彩循环 / 彩虹 / 流光 / 闪烁 / 闪电 / 星空 / 沉浸式游戏 / 音乐系列 / 雷蛇联动 / 状态显示 / 开机 / 脉冲
- 🎨 可视化调色：快捷色块、R/G/B 滑杆、十六进制输入；每种灯效独立记忆参数
- ⚡ 调整后约 0.4 秒自动下发，也可手动「应用灯效」
- 🔁 首次启动自动导入 iGC 已保存的整套预设，之后完全脱离 iGC
- 🖥 托盘常驻、单实例唤起、关闭窗口最小化
- 🚀 面板内一键开机自启（`--tray` 静默启动，无需管理员权限）
- 🌙 睡眠/休眠唤醒后自动恢复灯效
- 📦 仅依赖 Windows 自带的 .NET Framework 4.8，无驱动、无服务、无第三方包

## 💻 系统要求

- Windows 10 / 11 64 位
- .NET Framework 4.8（Win10 1903+ / Win11 自带）
- 带 ARGB 灯控的七彩虹 iGame / 战斧系列主板
- 已安装官方 iGC.Lite（用于提供灯光组件）

## ⚠️ 已知限制

- 只控制主板灯光，不处理显卡 / 内存 / 键盘 / 控制器
- 未移植 iGC 的「空间灯控」画布编辑器
- 沉浸式游戏、雷蛇联动、音乐类灯效只下发基础参数，效果可能不完整
- 「状态显示」使用面板中手动设定的温度值（无法读取硬件传感器）
- 不能与 iGC 同时运行（会争抢主板 RGB 控制器）
