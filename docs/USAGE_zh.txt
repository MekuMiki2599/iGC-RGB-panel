================================================================
 iGCRGB —— 七彩虹 iGame 主板灯光控制面板  v2.0
================================================================

【这是什么】

  把 iGC.Lite 里的「灯光控制」整条链路单独提取出来做成的桌面程序：
  - 双击 iGCRGB.exe 直接打开设置面板，不用再打开 iGC；
  - 面板里完整提供了 iGC 灯光页的全部灯效与参数：
    17 种灯效、颜色、亮度、速度、方向、灵敏度、温度显示、灯光总开关；
  - 只加载主板灯光所需的官方组件（iGameMBoard / iGameEasyCalc /
    iGameSpaceCalc），不加载风扇、LCD、硬件监控、广告等模块；
  - 实测占用：后台常驻 CPU 约 0.2%，最小化到托盘后内存可降到几 MB。


【快速开始】

  1. 双击 iGCRGB.exe，打开设置面板；
     （第一次启动会自动读取 iGC 里已保存的灯光预设，无需重新设置）

  2. 左侧选择灯效，右侧调颜色 / 亮度 / 速度 / 方向，
     勾选了「调整后立即生效」后改动会立刻下发到主板；
     也可以点右下角「应用灯效」手动应用。

  3. 右上角是「灯光总开关」，关掉等于 iGC 里的关灯。

  4. 关闭窗口默认最小化到托盘，灯效继续运行。
     完全退出：右键任务栏托盘里的 iGCRGB 图标 → 退出。
     （如果不需要后台常驻，也可以关掉「关闭窗口时最小化到托盘」）


【面板功能说明】

  灯效列表
    关灯 / 常亮 / 呼吸 / 色彩循环 / 彩虹 / 流光 / 闪烁 / 闪电 /
    星空 / 沉浸式游戏 / 音乐 / 音乐 A / 音乐 C / 音乐 D /
    雷蛇联动 / 状态显示 / 开机 / 脉冲

  颜色
    10 个快捷色块，或者拖动 R/G/B 滑杆，或直接输入十六进制色值。
    每种灯效都会单独记住自己的颜色和参数，切换灯效不会互相覆盖。

  亮度        0 - 255
  速度        1 - 10（流光、呼吸、闪烁等动态灯效）
  方向        「流光」类灯效的正向 / 反向
  灵敏度      音乐类灯效的律动灵敏度
  温度显示    「状态显示」灯效专用：CPU/GPU、当前温度、低/高温阈值

  应用与启动
    调整后立即生效        改动参数后自动下发（约 0.4 秒防抖）
    开机自动启动          登录 Windows 后自动在托盘启动并应用灯光
    关闭窗口时最小化到托盘 关闭即退出可取消勾选
    从 iGC 导入预设        重新读取 iGC 保存的整套灯光配置
    恢复默认              恢复出厂默认灯光设置


【与 iGC 的关系 / 注意事项】

  · 不要同时运行 iGC 和 iGCRGB。两者都会占用主板 RGB 控制器，会互相抢灯；
    如果检测不到设备，面板右上角会显示「未连接」，并每 8 秒自动重试。

  · 本工具自带所需的官方灯光组件（就在 iGameAPI 文件夹里），
    以后即使卸载 iGC，iGCRGB 依然可以正常工作；
    只是「从 iGC 导入预设」会失效，改用面板里的设置即可。

  · 如果 iGC 升级了版本、或主板灯效出现异常，可以从新版 iGC 目录复制以下文件覆盖：
      iGameAPI\iGameMBoard.dll
      iGameAPI\iGameEasyCalc.dll
      iGameAPI\iGameSpaceCalc.dll
      iGameAPI.Contracts.dll

  · 本工具只控制主板灯光（iGC 识别到的 MotherBoard 设备）。
    显卡、内存、键盘、控制器等灯效不在处理范围内。

  · iGC 的「空间灯控」是在画布上摆放灯珠的复杂编辑器，本工具没有移植；
    面板支持的是普通整体灯效（iGC 里的“整体”模式）。

  · 沉浸式游戏、雷蛇联动、音乐类灯效在 iGC 里还需要额外模块或实时数据，
    本工具只下发基础参数，效果可能不完整；
    常亮 / 呼吸 / 流光 / 彩虹 / 闪烁 / 星空等常见灯效完全可用。

  · 睡眠/休眠唤醒后会自动重新初始化灯效。


【配置文件】

  程序会在自己的目录下生成 settings.json（如果目录不可写，会放到
  %LOCALAPPDATA%\iGCRGB\）。里面保存全部灯效参数和界面选项，
  想备份或迁移直接复制这个文件即可。

  日志：iGCRGB.log（排错时先看这里）


【系统要求】

  · Windows 10 / 11 64 位
  · .NET Framework 4.8（Win10 1903 之后、Win11 均自带）
  · 带 ARGB 灯控的七彩虹 iGame / 战斧系列主板


【卸载】

  1. 右键托盘图标 → 退出；
  2. 打开面板，取消勾选「开机自动启动」；
  3. 删除整个文件夹。
     本工具不安装服务、不安装驱动、不写系统目录。


【排错】

  · 面板右上角显示「未连接」：
    确认没有同时打开 iGC；稍等几秒会自动重试。
  · 灯效和 iGC 里显示的不一样：
    点「从 iGC 导入预设」重新读取一次。
  · 开机没有自动应用：
    确认「开机自动启动」是打开的；若公司电脑有安全策略拦截，
    可手动按 Win+R 输入 shell:startup，把 iGCRGB.exe 的快捷方式放进去，
    并在快捷方式属性里加上 --tray 参数。
